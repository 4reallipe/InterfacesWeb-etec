Este repositório reúne os exercícios, testes práticos e projetos desenvolvidos na disciplina de **Interfaces Web**, integrante do curso técnico em **Informática para Internet** na **ETEC**.

O objetivo desta matéria é aprender a construir interfaces para a web desde a sua estrutura de marcação até a estilização e dinamismo, além de compreender a história e evolução das tecnologias web.
